# Creature assets

- `bat/vampire/bat_v5.blend`: rubberduck, CC0 — <https://opengameart.org/content/vampire-bat-animated>
- `moth/moth.glb`: Amatsukast, CC BY-NC-SA 4.0 — <https://sketchfab.com/3d-models/moth-fafcd79b60964e57a532e74706af6d16>

The `.blend` files are packed runtime copies so Blender retains the original
textures and animation actions. The OBJ files are legacy MuJoCo conversions.
